# 最安スキャン（janscaner）

商品のバーコード（JANコード）をスキャンすると、Yahoo!ショッピングと楽天市場を同時に検索して、いちばん安く買えるショップを表示する iOS アプリです。

## できること

- **スキャン**：カメラでJAN（EAN-13 / EAN-8）を読み取り。ライト、手入力、チェックディジット検証つき
- **最安値の表示**：送料無料かどうか、ポイント倍率、相場（中央値）との差をひと目で
- **価格の分布**：何店舗がいくらで売っているかをバーで表示
- **絞り込み**：サイト別・送料無料のみ
- **ほかのサイト**：Amazon・価格.com・ヨドバシ・メルカリ・Googleショッピングの検索結果をワンタップで
- **履歴**：スキャンした商品と最安値を保存。再検索で値下がりを ▼ で表示、お気に入り登録

## 初期設定（アプリの「設定」タブ）

| サイト | 必要なもの | 取得先 |
|---|---|---|
| Yahoo!ショッピング | Client ID | Yahoo!デベロッパーネットワーク |
| 楽天市場 | アプリID・アクセスキー・登録したURL | 楽天ウェブサービス |

楽天の新API（2026年〜）は Referer チェックがあるため、アプリ登録時に入力したURLを「登録したURL」に入れてください。キーは端末のキーチェーンにだけ保存されます。

## ビルド

`main` に push すると GitHub Actions が XcodeGen でプロジェクトを作り、**未署名の ipa** をビルドします。

- Releases の `build-番号` に `JanScanner.ipa` が添付されます
- お手持ちの証明書で署名してインストールしてください

## 構成

```
JanScanner/
  App/        起動・タブ
  Models/     JAN検証、価格データ、履歴（SwiftData）
  Services/   Yahoo!・楽天のAPI、キー保存
  Views/      スキャン / 検索結果 / 履歴 / 設定
  Design/     色・共通部品
```
